# A fictional worked example

`corpus.json` here is **entirely invented** — made-up creators, made-up numbers,
and a deliberately unrelated niche (woodworking) so that nobody mistakes it for
something to copy.

It exists for one reason: to show you the *shape* of a finished corpus before
you build your own.

Things worth noticing as you read it:

- **The two creators have genuinely different numbers.** ~2.2s per composition
  versus ~4.0s, 30-second videos versus 100-second ones. They are never averaged
  together. That separation is the point.
- **Every `lesson` transfers.** None of them say "talk about woodworking." Each
  states a principle you could apply in an entirely different field. That is the
  test: if a lesson cannot be stated without naming the creator's topic, it
  describes the skin rather than the grammar.
- **`risk_if_copied_wholesale` is blunt.** It says plainly what would go wrong.
  A flattering version of that field is worse than not writing it.
- **The synthesis takes from both and leaves things behind.** It is not "be like
  creator A." It names a combination, including what is explicitly rejected.

`voice/voice.example.json` is the matching profile for the same fictional person.
